## Solver

- Setelah mendapatkan zip, ekstrak lalu akan mendapatkan 10000 file dengan format `midi` dengan sebuah file `txt`
- baca `note.txt` lalu akan mendapatkan hint mengalikan semua pitch yang berada di masing-masing file, lalu jumlahkan dengan hasil file lainnya
- menggunakan `python` dengan library `mido` ambil semua pitch dalam satu file lalu kalikan semua
- ulangi dengan file lain sampai 10000 file, lalu jumlahkan semuanya
- ubah tiap 2 digit menjadi sebuah not musik sesuai dengan format not musik midi, lalu gabungkan tanpa spasi
- wrap up dengan format flag, akhirnya dapatlah flagnya
