# Osint

## Author

Nikoo

## Categories

Miscellaneous

## Description

Yesterday I just saw a post about the competitions in ITFEST 2025 on one of the social media platforms but now I only remember CTF can you tell me if there are any other competitions?

**Note:** Messages are written in lowercase wrapped in ITFEST25 flag format and separating each word with an underscore (_).

## Solver

### Langkah 1: Pencarian Instagram Account
Cari akun Instagram dengan username `itfestmicroipb` yang merupakan akun resmi ITFEST 2025.

### Langkah 2: Identifikasi Post Target
Temukan postingan dengan judul "What's on ITFEST 2025" yang berisi informasi tentang kompetisi-kompetisi yang ada di ITFEST 2025.

### Langkah 3: Decode Mouse Code
Pada postingan tersebut, terdapat mouse code yang perlu di-decode untuk mendapatkan pesan tersembunyi.

### Langkah 4: Format Flag
Sesuai dengan instruksi pada note, format pesan yang ditemukan menjadi flag dengan format ITFEST25{} dan pisahkan setiap kata dengan underscore (_).

## Flag

```
ITFEST25{yakali_ngga_tau_itfest?}
```
